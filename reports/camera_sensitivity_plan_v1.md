# Correlation-aware pathway sensitivity — version 1

10 October 2026. This is a post hoc sensitivity requested after primary enrichment, gene-level, block-direction and Bayesian results were known. It is not outcome-blind, externally registered or a new confirmatory tier. No CAMERA outcomes have been inspected at this specification.

Assess all five originally frozen Hallmark pathways and all three original contrasts, using the nine conservative block–condition profiles, original count filter and expression-selected symbol representatives. Retain literal memberships and the original tested-symbol universe; no leading-edge selection or alias expansion. Blocks are 68_3/batch1, 68_3/batch2 and 69_2/batch1. Match metadata by unique profile identity and verify a complete 3×3 block/condition table. Model ~ block + condition has five coefficients and four residual degrees of freedom. Do not add a background term confounded with block.

Reconstruct DESeq2 median-ratio size factors on the full filtered count matrix without rerunning differential expression. Convert them to effective library sizes with the declared common scale. limma 3.68.5 voom uses raw integer counts for the selected 21,098 symbol representatives, effective library sizes, span 0.5, no additional between-library normalization and observation precision weights. The fitted objects and mean–variance diagnostic will be retained.

Use expression-based CAMERA (not cameraPR) with directional parametric statistics and voom weights. Main sensitivity estimates each set's average residual inter-gene correlation (inter.gene.cor=NA), disallowing negative-correlation variance deflation. The separately specified comparison uses fixed inter.gene.cor=0.01. Apply BH across the 15 pathway–contrast tests separately within each mode; do not use CAMERA's per-contrast internal FDR as the manuscript q. Preserve all 30 results, membership losses, estimated correlations, variance-inflation factors and numerical warnings. A nonsignificant or directionally discordant result is reported without selecting another setting.

These tests remain competitive and model-dependent. Four residual degrees of freedom constrain correlation estimation; correlation adjustment is not additional biological replication. Changes relative to fgsea include normalization/precision modeling and test statistics, so they cannot be attributed solely to correlation. Treat differences between treated days as descriptive; unknown control harvest composition can affect each day/common-control contrast. No source-contact, public release or portal update is part of this task.

Validation: reject duplicate/unmatched profile or gene keys, noninteger/negative counts, empty block–condition cells, rank deficiency, inconsistent frozen memberships and invalid contrasts. Verify all 15 tests per mode and joint-family BH. Reproduce the numeric tables in an isolated working directory from supplied derived counts and mappings, without the primary RDS. Preserve original primary, targeted, DNA and Bayesian freezes/results.

Sources: Wu & Smyth 2012, doi:10.1093/nar/gks461; official limma 3.68.5 manual (CAMERA and voom); pinned software sources and licenses in metadata/camera_*_source.json.
