# OXPHOS alias mapping sensitivity (post-freeze)

Run 2026-09-18 with `make oxphos-alias-sensitivity`. This is a **post-result annotation sensitivity**, not an amendment to the frozen primary v1.0 analysis. The original 182-member mapped OXPHOS result and all other primary outputs remain authoritative and unchanged.

The frozen Hallmark OXPHOS set contains 200 symbols. Its literal comparison with the deposited, older featureCounts annotation matched 182. We downloaded the [HGNC complete approved dataset](https://www.genenames.org/download/) from [HGNC's documented current TSV endpoint](https://storage.googleapis.com/public-download-files/hgnc/tsv/tsv/hgnc_complete_set.txt) on 2026-09-18 and retained the unchanged bytes under `data/raw/hgnc/`. SHA-256: `b3752a7668b90a24ef555495ee1acaee40999622859c2c452354307a73d7790c`. The original annotation's versioned Ensembl IDs were reduced to stable IDs solely for one-to-one matching to HGNC approved symbols. This recovered 15 current ATP5 symbols and TOMM70 via existing source genes under older names. BCKDHA and CASP7 have exact source annotation names but do not survive the *frozen* count/symbol filter; they were not added. Every identity and decision is in `tables/oxphos_alias/alias_mapping.csv`; duplicates or ambiguous matches fail the script.

For each existing primary, omitted-block, RIN/library and descriptive-block rank, the script first reruns the 182-member one-set baseline, then renames only the 16 verified rank symbols and reruns the same 200-member pathway with 198 mapped genes. Rank values, gene universe, seed, fgsea version/settings, biological profiles and model coefficients are unchanged. Single-pathway baseline estimates differ slightly from the original frozen multi-set run because fgsea estimates normalization against the set collection and Monte Carlo execution; **compare within this paired one-set sensitivity**, not a substituted q-value for the original analysis. The same-method baseline is close to the frozen NES (2.479, 2.496, −1.827).

| Contrast | Baseline mapped / NES | Alias mapped / NES | Δ NES | Alias leading-edge ATP5 members | Directional result |
|---|---:|---:|---:|---:|---|
| Day 1 vs common control | 182 / 2.486 | 198 / 2.551 | +0.065 | 12 | robust |
| Day 3 vs common control | 182 / 2.501 | 198 / 2.593 | +0.092 | 14 | robust |
| Treated Day 3 vs Day 1 | 182 / −1.827 | 198 / −1.866 | −0.040 | 8 | block-dependent |

Both day-specific results retain positive enrichment and the full frozen directional robustness pattern; the direct treated-day contrast remains block-dependent. Thus the key OXPHOS observation is **not an artifact of dropping the ATP5 members**. Its measured magnitude is modestly higher when the verified aliases are restored, but the temporal claim remains limited. One-set nominal p-values and an exploratory Bonferroni-by-15 column are retained in `tables/oxphos_alias/primary_comparison.csv` for transparency; neither replaces the frozen 15-test BH values or creates a new confirmatory family. Full sensitivity output, session information, warnings and source hashes are retained. Descriptive block ranks contain many exact ties; lexical ranking is fixed, but a separate tie-rule sensitivity was not run.

This sensitivity identifies ATP synthase-related transcripts in leading edges. It does not measure ATP synthase activity, respiration or treatment-specific persistence. Control harvest-day labels are still missing. The local HGNC snapshot is checksum pinned; if it is absent, the script fails rather than silently downloading a newer release.
